# Python learning workspace

## Goal

Build practical Python ability over seven learning days, spending 1–2 hours daily. Python is the focus; Django is excluded. Small Gen AI applications are a later application of the fundamentals.

## Learning workflow

1. Recall previous material without notes.
2. Learn a few concepts with prediction questions.
3. Write a small application with guided hints.
4. Complete a related task independently.
5. Review mistakes and update CURRICULUM.md and PROGRESS.md.

The learner writes exercise solutions. Tutor-created notes, exercise specifications, and starter files are welcome; do not fill in independent exercise solutions before an attempt unless requested.

## Continue in a new chat

Use a chat with access to this same folder and say:

> Continue my Python learning. Read README.md, CURRICULUM.md, PROGRESS.md, and the latest daily notes first. Start with a short recall check and adapt today's lesson to my demonstrated skills. Give hints before solutions.

Saved files carry the learning record. Do not assume every new chat has the previous chat transcript or that local files automatically sync into ChatGPT project sources.

## Files

- CURRICULUM.md: current, adaptable lesson plan.
- PROGRESS.md: evidence of understanding, misconceptions, and next steps.
- [Day 1](Day%201/README.md): tutorial checkpoints complete; project skipped.
- [Day 2](Day%202/README.md): next tutorial and checkpoints.

Open this directory in VS Code to work on the same saved files the tutor can inspect. Save changes before requesting review.
