# Adaptive Python curriculum

Initial plan recorded 2026-10-10. Days are learning sessions, not fixed calendar dates.

| Day | Focus | Application |
| --- | --- | --- |
| 1 | Tutorial checkpoints complete; retain conversion/None review | Demo and homework skipped by request |
| 2 | Arguments, scope, shared mutable data, copying, combining functions | Small independent checkpoints; project choice later |
| 3 | Exceptions, tracebacks, validation, debugging | Robust input flow and broken-code exercises |
| 4 | Files, paths, context managers, JSON, file errors | Save/load/search notes |
| 5 | Modules, imports, virtual environments, packages, basic classes | Organise a small application |
| 6 | HTTP/API basics, nested JSON, environment variables, response errors | Small API client |
| 7 | Independent integration and review; small Gen AI feature if ready | Capstone |

## Adaptation rules

- Statuses: needs practice, developing, ready to move on, not assessed.
- Move a topic out of dedicated lessons after independent implementation, explanation, and next-session recall. Continue brief review.
- Keep uncertain topics and reduce later scope if needed.
- Add topics as time and demonstrated readiness permit; do not prioritise finishing the calendar over understanding.
- Error/file handling need focused practice. Threads are deferred.
- No topic has yet passed an independent implementation and next-session recall check.
