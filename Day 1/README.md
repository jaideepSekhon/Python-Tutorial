## How to practise

- Save examples in a scratch .py file here if you want to run them.
- From its folder, run a saved file with `python filename.py`, or `py filename.py` if that is your working Windows launcher.
- Comments beginning with # explain code; they are not additional statements.
- Checkpoint answers are deliberately omitted. Send your attempts for feedback.
- Ask about any line whose behaviour you cannot explain.

## What comes afterward

After the tutorial checkpoints, we will build a text analyser together and then specify an independent project. Neither project has been created yet.

## Completion criteria

Demonstrate deliberate conversion, text manipulation, choosing lists or dictionaries, correctly bounded loops, and functions with useful return values. Reading alone does not mark a topic mastered.
